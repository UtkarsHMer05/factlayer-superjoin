# FactLayer interface

Mode: Operate. The approved handoff delegates routine visual decisions and specifies an evidence inspection workflow; no extra design approval round was introduced.

The visual direction is a library research desk: quiet sage navigation, white source records, forest-green actions, and compact tabular facts. This carries the source comparison task into facts, documents, failures, and exports. DM Sans is bundled locally; no external font service is required. Source pages supply the imagery.

The first surface prioritizes assertion, value/context, then source. Comparison detail reads the conclusion before showing both claims, followed by original evidence. Uncertainty is a visible state; color always has a text label. On mobile, table rows become stacked records and source/detail views fill the viewport.

Direction deliberation: review docket, spreadsheet ledger, research notebook, library catalogue, instrument panel, library research desk, editorial fact-check sheet. The concept-seed assigned the sixth direction. Experimental typography, origami steps, rhythm-machine controls, broadcast captions and angled timetable forms reduce document-inspection clarity; their useful disciplines (precise states, consistent alignment, reversible inspection) are retained without decorative metaphors. Code-first implementation follows the handoff's request for a compact UI and delegated execution.
